# 🎮 Tetris Game

A classic Tetris puzzle game recreated as a personal coding project.

## About the Game
Tetris is a classic puzzle game where players arrange falling blocks (called tetrominoes) to create complete horizontal lines. Completed lines disappear, and the player earns points.

## How to Play
- Move blocks left and right.
- Rotate blocks to find the best position.
- Complete horizontal lines to clear them.
- Try to get the highest score!
- Don't let the blocks reach the top.
